# 第 16 章 · 类与对象

> 本文译自 [libropython.es](https://libropython.es/chap16.html)。原文为西班牙语，翻译仅供学习使用。

到目前为止，我们已经定义了类，并创建了表示一天中时刻和一年中日期的对象。我们还定义了创建、修改这些对象并用它们进行计算的方法。

在本章中，我们将继续面向对象编程（OOP）之旅，定义表示几何对象的类，包括点、线、矩形和圆。我们将编写创建和修改这些对象的方法，并用 `jupyturtle` 模块绘制它们。

我将用这些类来演示 OOP 的主题，包括对象的同一性与等价性、浅拷贝与深拷贝，以及多态。

## 16.1 创建 Point

在计算机图形学中，屏幕上的位置通常用 `x`-`y` 平面中的一对坐标表示。按惯例，点 `(0, 0)` 通常表示屏幕的左上角，而 `(x, y)` 表示从原点向右 `x` 个单位、向下 `y` 个单位的点。与你可能在数学课上学过的笛卡尔坐标系相比，`y` 轴是反的。

在 Python 中表示点有几种方式：

*   我们可以把坐标分别存储在 `x` 和 `y` 两个变量中。

*   我们可以把坐标作为列表或元组中的元素存储。

*   我们可以创建一个新类型，把点表示为对象。

在面向对象编程中，最惯用的方式是创建一个新类型。为此，我们从 `Point` 的类定义开始。

```python
class Point:
    """Represents a point in 2-D space."""

    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        return f'Point({self.x}, {self.y})'
```

`__init__` 方法接收坐标作为参数，并把它们赋给属性 `x` 和 `y`。`__str__` 方法返回 `Point` 的字符串表示。

现在我们可以这样实例化并显示 `Point` 对象。

```python
start = Point(0, 0)
print(start)
# Point(0, 0)
```

下面的图展示了新对象的状态。

```python
from diagram import make_frame, make_binding

d1 = vars(start)
frame = make_frame(d1, name='Point', dy=-0.25, offsetx=0.18)
binding = make_binding('start', frame)
```

和往常一样，程序员定义的类型用一个盒子表示，盒子外是类型名，盒子内是属性。

一般来说，程序员定义的类型是可变的，所以我们可以写一个像 `translate` 这样的方法，接收两个数字 `dx` 和 `dy`，把它们加到属性 `x` 和 `y` 上。

```python
%%add_method_to Point

    def translate(self, dx, dy):
        self.x += dx
        self.y += dy
```

这个函数把 `Point` 从平面上的一个位置移动到另一个位置。如果我们不想修改现有 `Point`，可以用 `copy` 复制原对象，然后修改副本。

```python
from copy import copy

end1 = copy(start)
end1.translate(300, 0)
print(end1)
# Point(300, 0)
```

我们可以把这些步骤封装进另一个名为 `translated` 的方法。

```python
%%add_method_to Point

    def translated(self, dx=0, dy=0):
        point = copy(self)
        point.translate(dx, dy)
        return point
```

就像 `sort` 方法修改列表而 `sorted` 函数创建新列表一样，现在我们有了修改 `Point` 的 `translate` 方法和创建新 `Point` 的 `translated` 方法。

下面是一个例子：

```python
end2 = start.translated(0, 150)
print(end2)
# Point(0, 150)
```

在下一节中，我们将用这些点来定义和绘制一条线。

## 16.2 创建 Line

现在定义一个表示两点之间线段的类。和往常一样，我们从 `__init__` 方法和 `__str__` 方法开始。

```python
class Line:
    def __init__(self, p1, p2):
        self.p1 = p1
        self.p2 = p2

    def __str__(self):
        return f'Line({self.p1}, {self.p2})'
```

用这两个方法，我们可以实例化并显示一个用来表示 `x` 轴的 `Line` 对象。

```python
line1 = Line(start, end1)
print(line1)
# Line(Point(0, 0), Point(300, 0))
```

当我们调用 `print` 并传入 `line` 作为参数时，`print` 在 `line` 上调用 `__str__`。`__str__` 方法用 f 字符串创建 `line` 的字符串表示。

f 字符串包含花括号中的两个表达式，`self.p1` 和 `self.p2`。当这些表达式被求值时，结果是 `Point` 对象。然后，当它们被转换成字符串时，`Point` 类的 `__str__` 方法被调用。

这就是为什么显示 `Line` 时，结果包含 `Point` 对象的字符串表示。

下面的对象图展示了这个 `Line` 对象的状态。

```python
from diagram import Binding, Value, Frame

d1 = vars(line1.p1)
frame1 = make_frame(d1, name='Point', dy=-0.25, offsetx=0.17)

d2 = vars(line1.p2)
frame2 = make_frame(d2, name='Point', dy=-0.25, offsetx=0.17)

binding1 = Binding(Value('start'), frame1, dx=0.4)
binding2 = Binding(Value('end'), frame2, dx=0.4)
frame3 = Frame([binding1, binding2], name='Line', dy=-0.9, offsetx=0.4, offsety=-0.25)

binding = make_binding('line1', frame3)
```

字符串表示和对象图对调试很有用，但这个例子的目标是生成图形，而不是文本！所以我们将用 `jupyturtle` 模块在屏幕上画线。

像我们在[第 4 章](#section_turtle_module)做的那样，我们用 `make_turtle` 创建 `Turtle` 对象和一个小画布。要画线，我们用 `jupyturtle` 模块的两个新函数：

*   `jumpto`，接收两个坐标，把 `Turtle` 移动到给定位置而不画线，以及

*   `moveto`，把 `Turtle` 从当前位置移动到给定位置，并在两者之间画一条线段。

我们这样导入它们。

```python
from jupyturtle import make_turtle, jumpto, moveto
```

而这里是一个绘制 `Line` 的方法。

```python
%%add_method_to Line

    def draw(self):
        jumpto(self.p1.x, self.p1.y)
        moveto(self.p2.x, self.p2.y)
```

为了展示如何使用，我再创建一条表示 `y` 轴的线。

```python
line2 = Line(start, end2)
print(line2)
```

然后绘制坐标轴。

```python
make_turtle()
line1.draw()
line2.draw()
```

随着我们定义并绘制更多对象，我们会再次使用这些线。但先谈谈对象的等价性与同一性。

## 16.3 等价性与同一性

假设我们创建两个坐标相同的点。

```python
p1 = Point(200, 100)
p2 = Point(200, 100)
```

如果我们用 `==` 运算符比较它们，得到程序员定义类型的默认行为——只有它们是同一个对象时结果才为 `True`，而它们不是。

```python
p1 == p2
# False
```

如果我们想改变这个行为，可以提供名为 `__eq__` 的特殊方法，定义两个 `Point` 对象相等意味着什么。

```python
%%add_method_to Point

    def __eq__(self, other):
        return (self.x == other.x) and (self.y == other.y)
```

这个定义认为两个 `Points` 相等，如果它们的属性相等。现在，当我们用 `==` 运算符时，它调用 `__eq__` 方法，表示 `p1` 和 `p2` 被视为相等。

```python
p1 == p2
# True
```

但 `is` 运算符仍然表示它们是不同的对象。

```python
p1 is p2
# False
```

无法覆盖 `is` 运算符——它总是检查对象是否同一。但对程序员定义的类型，你可以覆盖 `==` 运算符，让它检查对象是否等价。你可以定义等价意味着什么。

## 16.4 创建 Rectangle

现在定义一个表示并绘制矩形的类。为简单起见，我们假设矩形是垂直或水平的，不倾斜。你认为我们应该用哪些属性来指定矩形的位置和大小？

至少有两种可能：

*   你可以指定矩形的宽和高，以及一个角的位置。

*   你可以指定两个相对的角。

在这一点上很难说哪种更好，所以我们实现第一种。下面是类定义。

```python
class Rectangle:
    """Represents a rectangle.

    attributes: width, height, corner.
    """
    def __init__(self, width, height, corner):
        self.width = width
        self.height = height
        self.corner = corner

    def __str__(self):
        return f'Rectangle({self.width}, {self.height}, {self.corner})'
```

和往常一样，`__init__` 方法把参数赋给属性，`__str__` 返回对象的字符串表示。现在我们可以实例化 `Rectangle` 对象，用 `Point` 作为左上角的位置。

```python
corner = Point(30, 20)
box1 = Rectangle(100, 50, corner)
print(box1)
# Rectangle(100, 50, Point(30, 20))
```

下面的图展示了这个对象的状态。

```python
from diagram import Binding, Value

def make_rectangle_binding(name, box, **options):
    d1 = vars(box.corner)
    frame_corner = make_frame(d1, name='Point', dy=-0.25, offsetx=0.07)

    d2 = dict(width=box.width, height=box.height)
    frame = make_frame(d2, name='Rectangle', dy=-0.25, offsetx=0.45)
    binding = Binding(Value('corner'), frame1, dx=0.92, draw_value=False, **options)
    frame.bindings.append(binding)

    binding = Binding(Value(name), frame)
    return binding, frame_corner

binding_box1, frame_corner1 = make_rectangle_binding('box1', box1)
```

要画矩形，我们用下面的方法创建四个表示角的 `Point` 对象。

```python
%%add_method_to Rectangle

    def make_points(self):
        p1 = self.corner
        p2 = p1.translated(self.width, 0)
        p3 = p2.translated(0, self.height)
        p4 = p3.translated(-self.width, 0)
        return p1, p2, p3, p4
```

然后创建四个表示边的 `Line` 对象。

```python
%%add_method_to Rectangle

    def make_lines(self):
        p1, p2, p3, p4 = self.make_points()
        return Line(p1, p2), Line(p2, p3), Line(p3, p4), Line(p4, p1)
```

然后绘制这些边。

```python
%%add_method_to Rectangle

    def draw(self):
        lines = self.make_lines()
        for line in lines:
            line.draw()
```

下面是一个例子。

```python
make_turtle()
line1.draw()
line2.draw()
box1.draw()
```

图中包含两条表示坐标轴的线。

## 16.5 修改矩形

现在考虑两个修改矩形的方法，`grow` 和 `translate`。我们将看到 `grow` 按预期工作，但 `translate` 有一个微妙的 bug。看看你能不能在我解释之前发现它。

`grow` 接收两个数字，`dwidth` 和 `dheight`，把它们加到矩形的属性 `width` 和 `height` 上。

```python
%%add_method_to Rectangle

    def grow(self, dwidth, dheight):
        self.width += dwidth
        self.height += dheight
```

下面是一个例子，通过创建 `box1` 的副本并在副本上调用 `grow` 来演示效果。

```python
box2 = copy(box1)
box2.grow(60, 40)
print(box2)
```

如果我们绘制 `box1` 和 `box2`，可以确认 `grow` 按预期工作。

```python
make_turtle()
line1.draw()
line2.draw()
box1.draw()
box2.draw()
```

现在看看 `translate` 会发生什么。它接收两个数字，`dx` 和 `dy`，把矩形在 `x` 和 `y` 方向上移动给定的距离。

```python
%%add_method_to Rectangle

    def translate(self, dx, dy):
        self.corner.translate(dx, dy)
```

为了演示效果，我们把 `box2` 向右、向下移动。

```python
box2.translate(30, 20)
print(box2)
```

现在看看如果我们再次绘制 `box1` 和 `box2` 会发生什么。

```python
make_turtle()
line1.draw()
line2.draw()
box1.draw()
box2.draw()
```

看起来两个矩形都移动了，这不是我们的本意！下一节解释哪里出了问题。

## 16.6 深拷贝

当我们用 `copy` 复制 `box1` 时，它复制了 `Rectangle` 对象，但没有复制它包含的 `Point` 对象。所以 `box1` 和 `box2` 是不同的对象，正如我们所愿。

```python
box1 is box2
# False
```

但它们的 `corner` 属性指向同一个对象。

```python
box1.corner is box2.corner
# True
```

下面的图展示了这些对象的状态。

```python
from diagram import Stack
from copy import deepcopy

binding_box1, frame_corner1 = make_rectangle_binding('box1', box1)
binding_box2, frame_corner2 = make_rectangle_binding('box2', box2, dy=0.4)
binding_box2.value.bindings.reverse()

stack = Stack([binding_box1, binding_box2], dy=-1.3)
```

`copy` 所做的称为**浅拷贝（copia superficial）**，因为它复制对象但不复制对象包含的对象。结果，改变一个 `Rectangle` 的 `width` 或 `height` 不会影响另一个，但改变共享 `Point` 的属性会影响两者！这种行为令人困惑且容易出错。

幸运的是，`copy` 模块提供了另一个名为 `deepcopy` 的函数，它不仅复制对象，还复制它引用的对象，以及*它们*引用的对象，依此类推。这个操作称为**深拷贝（copia profunda）**。

为了演示，我们从一个包含新 `Point` 的新 `Rectangle` 开始。

```python
corner = Point(20, 20)
box3 = Rectangle(100, 50, corner)
print(box3)
```

然后做深拷贝。

```python
from copy import deepcopy

box4 = deepcopy(box3)
```

我们可以确认两个 `Rectangle` 对象引用不同的 `Point` 对象。

```python
box3.corner is box4.corner
# False
```

因为 `box3` 和 `box4` 是完全分开的对象，我们可以修改一个而不影响另一个。为了演示，我们移动 `box3` 并让 `box4` 变大。

```python
box3.translate(50, 30)
box4.grow(100, 60)
```

我们可以确认效果符合预期。

```python
make_turtle()
line1.draw()
line2.draw()
box3.draw()
box4.draw()
```

## 16.7 多态

在上面的例子中，我们在两个 `Line` 对象和两个 `Rectangle` 对象上调用了 `draw` 方法。我们可以通过创建对象列表更简洁地做同样的事。

```python
shapes = [line1, line2, box3, box4]
```

这个列表的元素类型不同，但它们都提供 `draw` 方法，所以我们可以遍历列表并在每个对象上调用 `draw`。

```python
make_turtle()

for shape in shapes:
    shape.draw()
```

循环的第一和第二次，`shape` 指向 `Line` 对象，所以调用 `draw` 时，执行的是 `Line` 类中定义的方法。

循环的第三和第四次，`shape` 指向 `Rectangle` 对象，所以调用 `draw` 时，执行的是 `Rectangle` 类中定义的方法。

从某种意义上说，每个对象都知道如何绘制自己。这个特性称为**多态（polimorfismo）**。这个词来自希腊语词根，意为“多种形式”。在面向对象编程中，多态是不同类型提供相同方法的能力，使得通过在不同类型的对象上调用相同方法可以执行很多计算——比如绘制形状。

作为本章末尾的练习，你将定义一个表示圆的新类，并提供 `draw` 方法。然后你可以用多态来绘制线、矩形和圆。

## 16.8 调试

在本章中，我们遇到了一个微妙的错误，它发生的原因是我们创建了一个被两个 `Rectangle` 对象共享的 `Point`，然后又修改了这个 `Point`。一般来说，有两种方法避免这类问题：你可以避免共享对象，也可以避免修改它们。

要避免共享对象，你可以用深拷贝，就像本章做的那样。

要避免修改对象，考虑用 `translated` 这样的纯函数替换 `translate` 这样的非纯函数。例如，下面是 `translated` 的一个版本，它创建新的 `Point`，从不修改其属性。

```python
def translated(self, dx=0, dy=0):
    x = self.x + dx
    y = self.y + dy
    return Point(x, y)
```

Python 提供了让避免修改对象更容易的功能。它们超出了本书的范围，但如果你好奇，问虚拟助手：“如何让 Python 对象不可变？”

创建新对象比修改现有对象花更多时间，但这个差异在实践中很少重要。避免共享对象和非纯函数的程序通常更容易开发、测试和调试——而最好的调试是你不需要做的调试。

## 16.9 词汇表

**浅拷贝：** 不复制嵌套对象的复制操作。

**深拷贝：** 也复制嵌套对象的复制操作。

**多态：** 方法或运算符适用于多种类型对象的能力。

### 16.10.2 练习

为 `Line` 类写一个 `__eq__` 方法，如果 `Line` 对象引用的 `Point` 对象等价（无论顺序），返回 `True`。

你可以用下面的框架开始。

```python
%%add_method_to Line

    def __eq__(self, other):
        return None
```

你可以用这些例子测试你的代码。

```python
start1 = Point(0, 0)
start2 = Point(0, 0)
end = Point(200, 100)
```

这个例子应该是 `True`，因为 `Line` 对象引用等价的 `Point` 对象，顺序相同。

```python
line_a = Line(start1, end)
line_b = Line(start2, end)
line_a == line_b    # should be True
```

这个例子应该是 `True`，因为 `Line` 对象引用等价的 `Point` 对象，顺序相反。

```python
line_c = Line(end, start1)
line_a == line_c     # should be True
```

等价应该始终是传递的——即如果 `line_a` 和 `line_b` 等价，且 `line_a` 和 `line_c` 等价，那么 `line_b` 和 `line_c` 也应该等价。

```python
line_b == line_c     # should be True
```

这个例子应该是 `False`，因为 `Line` 对象引用不等价的 `Point` 对象。

```python
line_d = Line(start1, start2)
line_a == line_d    # should be False
```

### 16.10.6 练习

写一个名为 `Circle` 的类定义，属性为 `center` 和 `radius`，其中 `center` 是 Point 对象，`radius` 是数字。包括特殊方法 `__init__` 和 `__str__`，以及一个名为 `draw` 的方法，用 `jupyturtle` 的函数绘制圆。

你可以用下面的函数，它是我们在第 4 章写的 `circle` 函数的一个版本。

```python
from jupyturtle import make_turtle, forward, left, right
import math

def draw_circle(radius):
    circumference = 2 * math.pi * radius
    n = 30
    length = circumference / n
    angle = 360 / n
    left(angle / 2)
    for i in range(n):
        forward(length)
        left(angle)
```

你可以用下面的例子测试你的代码。我们从一个 `width` 和 `height` 均为 `100` 的正方形 `Rectangle` 开始。

```python
corner = Point(20, 20)
rectangle = Rectangle(100, 100, corner)
```

下面的代码应该创建一个正好嵌进正方形的 `Circle`。

```python
center = rectangle.midpoint()
radius = rectangle.height / 2

circle = Circle(center, radius)
print(circle)
```

如果一切正常，下面的代码应该把圆画在正方形内（与四条边相切）。

```python
make_turtle(delay=0.01)

rectangle.draw()
circle.draw()
```
