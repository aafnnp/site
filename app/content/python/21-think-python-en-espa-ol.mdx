# Think Python（中文版）

> 本文译自 [libropython.es](https://libropython.es/)。原文为西班牙语，翻译仅供学习使用。

《Think Python》是一本面向从未编程过的人、或尝试过却遇到困难的人的 Python 入门书。

这个中文版翻译自 Allen B. Downey 的《Think Python: How to Think Like a Computer Scientist》第三版西班牙语译本（由 midudev 翻译），并再译为中文。

你可以在 [Bookshop.org](https://bookshop.org/a/98697/9781098155438) 和 [Amazon](https://www.amazon.com/_/dp/1098155432) 购买 *Think Python 3e* 的纸质版和电子版。

下面是这本书在 Green Tea Press 的主页。

[下载完整 PDF](https://greenteapress.com/wp/think-python-3rd-edition/)
