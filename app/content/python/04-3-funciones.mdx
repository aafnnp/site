# 第 3 章 · 函数

> 本文译自 [libropython.es](https://libropython.es/chap03.html)。原文为西班牙语，翻译仅供学习使用。

在上一章，我们使用了 Python 提供的一些函数，如 `int` 和 `float`，以及 `math` 模块提供的一些函数，如 `sqrt` 和 `pow`。在这一章，你将学习如何创建并运行自己的函数。我们还会看到函数如何调用另一个函数。作为例子，我们会打印 Monty Python 歌曲的歌词。这些荒诞的例子展示了一个重要的特性：编写自己的函数的能力是编程的基础。

本章还会引入一种新语句，`for` 循环，它用于重复执行某个计算。

## 3.1 定义新函数

**函数定义**指定了新函数的名称，以及在调用该函数时要执行的语句序列。下面是一个例子：

```python
def print_lyrics():
    print("I'm a lumberjack, and I'm okay.")
    print("I sleep all night and I work all day.")
```

`def` 是一个关键字，表示这是一段函数定义。函数名是 `print_lyrics`。任何合法的变量名都可以作为合法的函数名。

名字后面的空括号表示该函数不接收参数。

函数定义的第一行称为**函数头（encabezado）**；其余部分称为**函数体（cuerpo）**。函数头必须以冒号结尾，函数体必须缩进。按照惯例，缩进始终是四个空格。这个函数的函数体是两条 `print` 语句；一般来说，函数体可以包含任意类型、任意数量的语句。

定义函数会创建一个**函数对象**，我们可以这样显示它。

```python
print_lyrics
# <function print_lyrics at 0x...>
```

输出表明 `print_lyrics` 是一个不接收参数的函数。`__main__` 是包含 `print_lyrics` 的模块的名字。

现在我们已经定义了一个函数，就可以像调用内置函数一样调用它。

```python
print_lyrics()
# I'm a lumberjack, and I'm okay.
# I sleep all night and I work all day.
```

函数执行时，会执行函数体中的语句，显示“The Lumberjack Song”的前两行。

## 3.2 参数

我们见过的一些函数需要参数；例如，当你调用 `abs` 时，要传入一个数字作为参数。有些函数接收多个参数；例如 `math.pow` 接收两个参数：底数和指数。

下面是一个接收一个参数的函数定义。

```python
def print_twice(string):
    print(string)
    print(string)
```

括号中的变量名是**参数（parámetro）**。当函数被调用时，参数的值被赋给这个参数。例如，我们可以这样调用 `print_twice`。

```python
print_twice('Dennis Moore, ')
# Dennis Moore, 
# Dennis Moore, 
```

执行这个函数的效果，等同于先把实参赋给形参，再执行函数体，就像这样。

```python
string = 'Dennis Moore, '
print(string)
print(string)
```

你也可以用变量作为实参。

```python
line = 'Dennis Moore, '
print_twice(line)
```

在这个例子中，`line` 的值被赋给了形参 `string`。

## 3.3 调用函数

一旦你定义了一个函数，就可以在另一个函数中使用它。为了演示，我们来写几个打印“The Spam Song”歌词的函数（[https://www.songfacts.com/lyrics/monty-python/the-spam-song](https://www.songfacts.com/lyrics/monty-python/the-spam-song)）。

> Spam, Spam, Spam, Spam,  
> Spam, Spam, Spam, Spam,  
> Spam, Spam,  
> (Lovely Spam, Wonderful Spam!)  
> Spam, Spam,

我们从下面这个接收两个参数的函数开始。

```python
def repeat(word, n):
    print(word * n)
```

我们可以用这个函数打印歌曲的第一行，像这样。

```python
spam = 'Spam, '
repeat(spam, 4)
# Spam, Spam, Spam, Spam, 
```

要显示前两行，我们可以定义一个使用 `repeat` 的新函数。

```python
def first_two_lines():
    repeat(spam, 4)
    repeat(spam, 4)
```

然后像这样调用它。

```python
first_two_lines()
```

要显示最后三行，我们可以定义另一个也使用 `repeat` 的函数。

```python
def last_three_lines():
    repeat(spam, 2)
    print('(Lovely Spam, Wonderful Spam!)')
    repeat(spam, 2)

last_three_lines()
```

最后，我们可以用一个打印整段的函数把它们整合起来。

```python
def print_verse():
    first_two_lines()
    last_three_lines()

print_verse()
```

当我们执行 `print_verse` 时，它调用 `first_two_lines`，后者调用 `repeat`，后者又调用 `print`。函数还真不少。

当然，我们本可以用更少的函数做到同样的事，但这个例子的目的是展示函数如何协同工作。

## 3.4 重复

如果我们想显示不止一段歌词，可以使用 `for` 语句。下面是一个简单的例子。

```python
for i in range(2):
    print(i)
# 0
# 1
```

第一行是以冒号结尾的循环头。第二行是循环体，必须缩进。

循环头以关键字 `for` 开头，后面是一个名为 `i` 的新变量，再后面是另一个关键字 `in`。它使用 `range` 函数创建两个值的序列，即 `0` 和 `1`。在 Python 中，开始计数时通常从 `0` 开始。

当 `for` 语句执行时，它把 `range` 的第一个值赋给 `i`，然后执行循环体中的 `print` 函数，显示 `0`。

当执行到循环体末尾时，它回到循环头，所以这种语句被称为**循环（bucle）**。第二次经过循环时，它把 `range` 的下一个值赋给 `i` 并显示它。由于这是 `range` 的最后一个值，循环结束。

下面是我们如何用 `for` 循环打印歌曲的两段歌词。

```python
for i in range(2):
    print("Verse", i)
    print_verse()
    print()
```

你可以把 `for` 循环放在函数里。例如，`print_n_verses` 接收一个名为 `n` 的参数（必须是整数），并显示指定数量的段落。

```python
def print_n_verses(n):
    for i in range(n):
        print_verse()
        print()
```

在这个例子中，我们没有在循环体中使用 `i`，但循环头里仍然必须有一个变量名。

## 3.5 变量和参数都是局部的

当你在函数内部创建变量时，它是**局部（local）**的，也就是说它只存在于函数内部。例如，下面的函数接收两个参数，把它们拼接起来，并把结果打印两次。

```python
def cat_twice(part1, part2):
    cat = part1 + part2
    print_twice(cat)
```

下面是一个使用它的例子：

```python
line1 = 'Always look on the '
line2 = 'bright side of life.'
cat_twice(line1, line2)
```

当 `cat_twice` 执行时，它创建了一个名为 `cat` 的局部变量，该变量在函数结束时被销毁。如果我们试图显示它，会得到一个 `NameError`：

```python
print(cat)
# NameError: name 'cat' is not defined
```

在函数外部，`cat` 没有定义。

参数也是局部的。例如，在 `cat_twice` 之外，不存在任何名为 `part1` 或 `part2` 的东西。

## 3.6 栈图

为了跟踪每个位置可以使用哪些变量，有时绘制一个**栈图（diagrama de pila）**会很有帮助。和状态图一样，栈图显示每个变量的值，但它还显示每个变量属于哪个函数。

每个函数用一个**帧（marco）**表示。帧是一个盒子，外面写着函数名，里面是函数的参数和局部变量。

下面是前面例子的栈图。

```python
from diagram import make_frame, Stack

d1 = dict(line1=line1, line2=line2)
frame1 = make_frame(d1, name='__main__', dy=-0.3, loc='left')

d2 = dict(part1=line1, part2=line2, cat=line1+line2)
frame2 = make_frame(d2, name='cat_twice', dy=-0.3,
                    offsetx=0.03, loc='left')

d3 = dict(string=line1+line2)
frame3 = make_frame(d3, name='print_twice',
                    offsetx=0.04, offsety=-0.3, loc='left')

d4 = {"?": line1+line2}
frame4 = make_frame(d4, name='print',
                    offsetx=-0.22, offsety=0, loc='left')

stack = Stack([frame1, frame2, frame3, frame4], dy=-0.8)

from diagram import diagram, adjust
width, height, x, y = [3.77, 2.9, 1.1, 2.65]
ax = diagram(width, height)
bbox = stack.draw(ax, x, y)
```

这些帧被组织在一个栈（stack）中，它指示哪个函数调用了哪个函数，依此类推。从下往上读：`print` 被 `print_twice` 调用，`print_twice` 被 `cat_twice` 调用，`cat_twice` 被 `__main__` 调用，`__main__` 是最顶层帧的特殊名字。当你在任何函数之外创建变量时，它属于 `__main__`。

在 `print` 的帧里，问号表示我们不知道参数的名字。如果你好奇，可以问虚拟助手：“Python 的 `print` 函数有哪些参数？”

## 3.7 回溯

当函数内部发生运行时错误时，Python 会显示正在执行的函数名、调用它的函数名，依此类推，沿着栈向上。为了看一个例子，我定义一个带有错误的 `print_twice` 版本：它试图打印 `cat`，那是另一个函数的局部变量。

```python
def print_twice(string):
    print(cat)            # NameError
    print(cat)
```

下面是我们执行 `cat_twice` 时发生的情况。

```python
# 这个单元格告诉 Jupyter 在发生运行时错误时提供详细的调试信息，
# 包括回溯（traceback）。
%xmode Verbose

cat_twice(line1, line2)
```

错误消息包含一个**回溯（traceback）**，它显示错误发生时正在执行的函数、调用它的函数，依此类推。在这个例子中，它显示 `cat_twice` 调用了 `print_twice`，而错误发生在 `print_twice` 中。

回溯中函数的顺序与栈图中帧的顺序相同。正在执行的函数在最下面。

## 3.8 为什么用函数？

你可能还不清楚为什么值得把程序拆分成函数。有几个原因：

*   创建新函数给了你为一段语句命名的机会，这让程序更容易阅读和调试。

*   函数可以消除重复代码，让程序更小。以后如果要修改，只需要改一个地方。

*   把长程序拆分成函数，让你可以逐个部分调试，再把它们组装成一个能工作的整体。

*   设计良好的函数通常对很多程序都有用。一旦你写好并调试好一个函数，就可以复用它。

## 3.9 调试

调试可能令人沮丧，但它也很有挑战性、很有趣，有时甚至很好玩。而且它是你能学到的最重要的技能之一。

从某种意义上说，调试就像做侦探工作。你得到线索，然后必须推断出导致你看到的结果的事件。

调试也像实验科学。一旦你对哪里出了问题有了想法，就修改程序再试一次。如果你的假设正确，你就能预测修改的结果，并朝着能工作的程序再进一步。如果你的假设错误，你就得提出一个新的假设。

对一些人来说，编程和调试是一回事；也就是说，编程就是逐步调试程序，直到它做你想做的事。其理念是，你应该从一个能工作的程序开始，做小的修改，边做边调试。

如果你发现自己花大量时间调试，这通常是一个信号，说明你在开始测试之前写了太多代码。如果步子迈得小一点，你可能会发现自己能更快地前进。

## 3.10 词汇表

**函数定义：** 创建函数的语句。

**函数头：** 函数定义的第一行。

**函数体：** 函数定义内部的语句序列。

**函数对象：** 由函数定义创建的值。函数名是一个指向函数对象的变量。

**参数：** 函数内部使用的名字，用来指代作为实参传入的值。

**循环：** 执行一条或多条语句（通常是重复执行）的语句。

**局部变量：** 在函数内部定义的变量，只能在函数内部访问。

**栈图：** 函数栈及其变量和变量所指向的值的图形化表示。

**帧：** 栈图中表示一次函数调用的盒子。它包含函数的局部变量和参数。

**回溯：** 发生异常时打印的、正在执行的函数列表。

### 3.11.5 练习

歌曲“99 Bottles of Beer”以这一段开头：

> 99 bottles of beer on the wall  
> 99 bottles of beer  
> Take one down, pass it around  
> 98 bottles of beer on the wall

第二段与之相同，只是以 98 瓶开头，以 97 瓶结尾。歌曲继续唱下去，唱很久很久，直到 0 瓶啤酒。

写一个名为 `bottle_verse` 的函数，接收一个数字作为参数，显示以给定瓶数开头的那段歌词。

提示：考虑先写一个能打印段落第一、第二或最后一行的函数，然后用它来写 `bottle_verse`。

用这个函数调用显示第一段。

```python
bottle_verse(99)
```

如果你想打印整首歌，可以用这个 `for` 循环，它从 `99` 倒数到 `1`。你不必完全理解这个例子；我们稍后会学习更多关于 `for` 循环和 `range` 函数的内容。

```python
for n in range(99, 0, -1):
    bottle_verse(n)
    print()
```
