# 第 1 章 · 编程是一种思考方式

> 本文译自 [libropython.es](https://libropython.es/chap01.html)。原文为西班牙语，翻译仅供学习使用。

本书的第一个目标是教你用 Python 编程。但学习编程意味着学习一种全新的思考方式，因此本书的第二个目标是帮助你像计算机科学家一样思考。这种思考方式融合了数学、工程学和自然科学各自的一些优点。像数学家一样，计算机科学家使用形式语言来表达思想——具体而言，即计算。像工程师一样，他们设计事物、把组件组装成系统，并权衡不同方案的利弊。像科学家一样，他们观察复杂系统的行为，提出假设并验证预测。

我们将从编程最基本的元素开始，循序渐进。在本章中，你会看到 Python 如何表示数字、字母和单词，并学习如何进行算术运算。

你也会开始学习编程的词汇，包括运算符、表达式、值和类型等术语。这套词汇很重要——理解本书其余部分、与其他程序员交流、以及使用和理解虚拟助手，都需要它。

## 1.1 算术运算符

**算术运算符**是表示某种算术计算的符号。例如，加号 `+` 执行加法。

```python
30 + 12
# 42
```

减号 `-` 是执行减法的运算符。

```python
43 - 1
# 42
```

星号 `*` 执行乘法。

```python
6 * 7
# 42
```

斜杠 `/` 执行除法：

```python
84 / 2
# 42.0
```

注意，除法的结果是 `42.0` 而不是 `42`。这是因为 Python 中有两类数字：

*   **整数（entero）**，表示没有小数部分的数字，以及

*   **浮点数（número de coma flotante）**，表示整数和带小数点的数字。

如果你对两个整数做加法、减法或乘法，结果是整数。但如果对两个整数做除法，结果是浮点数。Python 还提供了另一个运算符 `//`，执行**整数除法**。整数除法的结果始终是整数。

```python
84 // 2
# 42
```

整数除法也叫“向下取整除法”，因为它总是向下舍入（朝“地板”方向）。

```python
85 // 2
# 42
```

最后，运算符 `**` 执行乘方，也就是把一个数提升到某个幂：

```python
7 ** 2
# 49
```

在其他一些语言中，插入符 `^` 用于乘方，但在 Python 中它是名为 XOR 的位运算符。如果你不了解位运算符，结果可能会出乎意料：

```python
7 ^ 2
# 5
```

本书不涉及位运算符，但你可以在 [http://wiki.python.org/moin/BitwiseOperators](http://wiki.python.org/moin/BitwiseOperators) 了解它们。

## 1.2 表达式

一组运算符和数字的组合称为**表达式**。表达式可以包含任意数量的运算符和数字。例如，下面是一个包含两个运算符的表达式。

```python
6 + 6 ** 2
# 42
```

注意，乘方先于加法执行。Python 遵循你可能在数学课上学过的运算顺序：乘方先于乘法和除法，乘法和除法先于加法和减法。

在下面的例子中，乘法先于加法执行。

```python
12 + 5 * 6
# 42
```

如果你想让加法先执行，可以使用括号。

```python
(12 + 5) * 6
# 102
```

每个表达式都有一个**值**。例如，表达式 `6 * 7` 的值是 `42`。

## 1.3 算术函数

除了算术运算符，Python 还提供了一些处理数字的**函数**。例如，`round` 函数接收一个浮点数，并把它舍入到最近的整数。

```python
round(42.4)
# 42
round(42.6)
# 43
```

`abs` 函数计算一个数的绝对值。对于正数，绝对值就是它本身。

```python
abs(42)
# 42
```

对于负数，绝对值是正数。

```python
abs(-42)
# 42
```

当我们像这样使用一个函数时，我们称在**调用**该函数。调用函数的表达式就是**函数调用**。

调用函数时，括号是必需的。如果你省略括号，会得到一个错误消息。

> 注：下面的单元格使用了 `%%expect`，这是 Jupyter 的一个“魔法命令”，表示我们预期该单元格中的代码会产生错误。更多相关信息请参阅 [Jupyter notebook 简介](https://colab.research.google.com/github/AllenDowney/ThinkPython/blob/v3/chapters/jupyter_intro.ipynb)。

```python
abs 42
# Cell In[..], line 1
#   abs 42
#        ^
# SyntaxError: invalid syntax
```

你可以忽略这条消息的第一行；它暂时不包含我们需要理解的信息。第二行是包含错误的代码，下方有一个插入符（`^`）指示错误被发现的位置。

最后一行表明这是一个**语法错误**，意思是表达式的结构有地方不对。在这个例子中，问题在于函数调用需要括号。

我们看看如果你同时省略括号*和*值会发生什么。

```python
abs
# <function abs(x, /)>
```

单独的函数名是一个有值的合法表达式。显示时，其值表明 `abs` 是一个函数，并包含我稍后会解释的额外信息。

## 1.4 字符串

除了数字，Python 还可以表示字母序列，称为**字符串（string）**，因为这些字母像项链上的珠子一样被串在一起。要写一个字符串，我们可以把一串字母放在单引号之间。

```python
'Hello'
```

使用双引号也是合法的。

```python
"world"
```

双引号更方便书写包含撇号（它与单引号是同一个符号）的字符串。

```python
"it's a small "
```

字符串还可以包含空格、标点符号和数字。

```python
'Well, '
```

运算符 `+` 也适用于字符串；它把两个字符串连接成一个字符串，这称为**拼接**。

```python
'Well, ' + "it's a small " + 'world.'
# "Well, it's a small world."
```

运算符 `*` 也适用于字符串；它复制一个字符串多份并拼接起来。

```python
'Spam, ' * 4
# 'Spam, Spam, Spam, Spam, '
```

其他算术运算符不适用于字符串。

Python 提供了一个名为 `len` 的函数，用来计算字符串的长度。

```python
len('Spam')
# 4
```

注意，`len` 计算的是引号之间的字母数量，但不包括引号。

创建字符串时，务必使用直引号。反引号（backtick）会导致语法错误。

```python
`Hello`
# SyntaxError: invalid syntax
```

弯引号（也叫排版引号）也是无效的。

```python
‘Hello’
# SyntaxError: invalid character
```

## 1.5 值与类型

到目前为止，我们已经见过三类值：

*   `2` 是整数，

*   `42.0` 是浮点数，以及

*   `'Hello'` 是字符串。

一类值称为一个**类型**。每个值都有一个类型——有时我们也说它“属于”某个类型。

Python 提供了一个名为 `type` 的函数，可以告诉你任意值的类型。整数的类型是 `int`。

```python
type(2)
# int
```

浮点数的类型是 `float`。

```python
type(42.0)
# float
```

字符串的类型是 `str`。

```python
type('Hello, World!')
# str
```

`int`、`float` 和 `str` 类型本身也可以当作函数使用。例如，`int` 可以接收一个浮点数并把它转换成整数（总是向下舍入）。

```python
int(42.9)
# 42
```

而 `float` 可以把整数转换成浮点值。

```python
float(42)
# 42.0
```

接下来是可能令人困惑的地方。如果你把一串数字放在引号里，会得到什么？

```python
'126'
```

它看起来像数字，但实际上是一个字符串。

```python
type('126')
# str
```

如果你试图把它当作数字使用，可能会出错。

```python
'126' / 3
# TypeError: unsupported operand type(s) for /: 'str' and 'int'
```

这个例子产生一个 `TypeError`，意思是表达式中的值——称为**操作数**——类型不正确。错误消息表明运算符 `/` 不支持这些值的类型，即 `str` 和 `int`。

如果你有一个包含数字的字符串，可以用 `int` 把它转换成整数。

```python
int('126') / 3
# 42.0
```

如果你有一个包含数字和小数点的字符串，可以用 `float` 把它转换成浮点数。

```python
float('12.6')
# 12.6
```

写大整数时，你可能会想在数字组之间用逗号，比如 `1,000,000`。这在 Python 中是合法表达式，但结果不是整数。

```python
1,000,000
# (1, 0, 0)
```

Python 把 `1,000,000` 解释为由逗号分隔的一组整数。这种序列我们稍后会学到。

你可以用下划线让大数字更易读。

```python
1_000_000
# 1000000
```

## 1.6 形式语言与自然语言

**自然语言**是人们所说的语言，如英语、西班牙语和法语。它们不是由人设计出来的，而是自然演化的。

**形式语言**是人们为特定用途而设计的语言。例如，数学家使用的符号就是一种特别擅长表示数字和符号之间关系的形式语言。同样，编程语言是为表达计算而设计的形式语言。

虽然形式语言和自然语言有一些共同特征，但存在重要差异：

*   **歧义性**：自然语言充满歧义，人们借助上下文线索和其他信息来处理。形式语言则被设计成几乎或完全没有歧义，这意味着任何程序都恰好只有一个含义，与上下文无关。

*   **冗余性**：为了弥补歧义并减少误解，自然语言使用冗余。因此它们往往比较啰嗦。形式语言冗余较少，更加简洁。

*   **字面性**：自然语言充满习语和隐喻。形式语言则是字面上说什么就是什么。

因为我们从小就说自然语言，有时很难适应形式语言。形式语言比自然语言更密集，所以阅读它们需要更多时间。此外，结构很重要，所以并不总是从上到下、从左到右阅读最好。最后，细节至关重要。在自然语言中可以容忍的小拼写和标点错误，在形式语言中可能造成天壤之别。

## 1.7 调试

程序员会犯错。由于某种任性，编程错误被称为 **bug**，而寻找错误的过程被称为**调试（debugging）**。

编程，尤其是调试，有时会引发强烈的情绪。如果你正与一个棘手的 bug 搏斗，可能会感到愤怒、悲伤或羞愧。

为这些反应做好准备，有助于你应对它们。一种方法是把计算机想象成一个员工，它有一些优点，如速度快、精确，也有一些特定的缺点，如缺乏同理心、无法把握全局。

你的工作是当一名好经理：想办法发挥它的长处、弥补它的短处；并想办法利用你的情绪投入问题，而不让这些反应妨碍你高效工作。

学习调试可能令人沮丧，但它是一项宝贵的技能，在编程之外的许多活动中都很有用。每一章末尾都有一个像这样的栏目，给出我的调试建议。希望它们对你有帮助！

## 1.8 词汇表

**算术运算符：** 一个符号，如 `+` 和 `*`，表示加法或乘法之类的算术运算。

**整数：** 一种类型，表示没有小数部分的数字。

**浮点数：** 一种类型，表示整数和带小数部分的数字。

**整数除法：** 运算符 `//`，对两个数做除法并向下舍入为整数。

**表达式：** 变量、值和运算符的组合。

**值：** 整数、浮点数或字符串——或其他我们稍后会看到的类型的值。

**函数：** 一段有名字的语句序列，执行某种有用的操作。函数可以有参数，也可以没有；可以产生结果，也可以不产生。

**函数调用：** 一种表达式（或表达式的一部分），执行一个函数。它由函数名后跟括号内的参数列表组成。

**语法错误：** 程序中的一种错误，使程序无法被解析——因此也无法运行。

**字符串：** 一种类型，表示字符序列。

**拼接：** 把两个字符串首尾相接。

**类型：** 值的一种类别。我们目前见过的类型有整数（`int`）、浮点数（`float`）和字符串（`str`）。

**操作数：** 运算符所操作的某个值。

**自然语言：** 人们所说的、自然演化的任何一种语言。

**形式语言：** 人们为特定目的设计的任何语言，例如表示数学思想或计算机程序。所有编程语言都是形式语言。

**bug：** 程序中的错误。

**调试：** 发现并修正错误的过程。

### 1.9.2 练习

你可能会好奇，当一个数以 `0.5` 结尾时 `round` 会怎么做。答案是它有时向上舍入，有时向下舍入。试试下面的例子，看你能不能找出它遵循的规则。

### 1.9.3 练习

当你学习一个新特性时，应该去尝试它，并故意犯错。这样你就能认识各种错误消息，等再次看到它们时就知道是什么意思了。现在故意犯错，总比以后无意中犯错好。
