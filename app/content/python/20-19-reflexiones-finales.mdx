# 第 19 章 · 最后的思考

> 本文译自 [libropython.es](https://libropython.es/chap19.html)。原文为西班牙语，翻译仅供学习使用。

学习编程并不容易，但如果你读到了这里，你已经有了一个好的开始。现在我对你如何继续学习、如何应用所学，有一些建议。

本书旨在作为编程的入门通识，所以我们没有聚焦于特定的应用。根据你的兴趣，有很多领域可以应用你的新技能。

如果你对数据科学感兴趣，我的三本书可能会让你喜欢：

- 《Think Stats: Exploratory Data Analysis》，O'Reilly Media，2014。
- 《Think Bayes: Bayesian Statistics in Python》，O'Reilly Media，2021。
- 《Think DSP: Digital Signal Processing in Python》，O'Reilly Media，2016。

如果你对物理建模和复杂系统感兴趣，也许你会喜欢：

- 《Modeling and Simulation in Python: An Introduction for Scientists and Engineers》，No Starch Press，2023。
- 《Think Complexity: Complexity Science and Computational Modeling》，O'Reilly Media，2018。

这些书使用 NumPy、SciPy、pandas 和其他用于数据科学与科学计算的 Python 库。

本书试图在编程的一般原则与 Python 的细节之间找到平衡。因此，它没有涵盖 Python 语言的所有特性。要了解更多关于 Python 的知识，以及使用它的好建议，我推荐 Luciano Ramalho 的《Fluent Python: Clear, Concise, and Effective Programming》第二版，O'Reilly Media，2022。

在编程入门之后，一个常见的下一步是学习数据结构与算法。我有一个关于这个主题的在写作品，叫《Data Structures and Information Retrieval in Python》。Green Tea Press 提供免费的电子版，地址是 [https://greenteapress.com](https://greenteapress.com)。

随着你处理更复杂的程序，你会遇到新的挑战。回顾本书关于调试的章节可能会对你有帮助。特别是，记住第 12 章调试的六个 R（按英文名）：阅读（read）、运行（run）、沉思（ruminate）、跟橡皮鸭讲（rubberduck）、后退（retreat）和休息（rest）。

本书建议了一些辅助调试的工具，包括 `print` 和 `repr` 函数、第 11 章的 `structshape` 函数，以及第 14 章的内置函数 `isinstance`、`hasattr` 和 `vars`。

它还建议了测试程序的工具，包括 `assert` 语句、`doctest` 模块和 `unittest` 模块。在程序中加入测试是预防和发现错误、节省调试时间的最好方式之一。

但最好的调试是你不需要做的调试。如果你像第 6 章描述的那样使用增量开发过程——边做边测试——你会犯更少的错误，出现错误时也能更快找到。此外，记住第 4 章的封装与泛化，它们在 Jupyter notebook 中开发代码时特别有用。

在整本书中，我建议了使用虚拟助手帮助你学习、编程和调试的方法。希望这些工具对你有用。

除了 ChatGPT 这样的虚拟助手，你可能还想用 Copilot 这样的工具，它在你输入时自动补全代码。一开始我没有推荐使用这些工具，因为它们对初学者来说可能难以招架。但也许现在你想探索它们了。

有效使用 AI 工具需要一些实验和思考，找到适合你的工作流。如果你觉得把代码从 ChatGPT 复制到 Jupyter 很烦，也许你更喜欢 Copilot 这样的东西。但你在组织提示词和解读回答时所做的认知工作，可能和工具生成的代码一样有价值，这与橡皮鸭调试异曲同工。

随着你编程经验的积累，也许你想探索其他开发环境。我认为 Jupyter notebook 是很好的起点，但它相对较新，不如传统集成开发环境（IDE）常用。对于 Python，最流行的 IDE 包括 PyCharm 和 Spyder——以及 Thonny，通常推荐给初学者。其他 IDE，如 Visual Studio Code 和 Eclipse，也支持其他编程语言。或者，作为更简单的选择，你可以用任何你喜欢的文本编辑器写 Python 程序。

在你继续编程之旅时，你不需要独自前行。如果你住在城市或城市附近，很可能有你可以加入的 Python 用户组。这些小组通常对初学者友好，所以不要害怕。如果你附近没有小组，也许你可以远程参加活动。此外，留意 Python 地区性会议。

提高编程技能的最好方式之一是学习另一种语言。如果你对统计学和数据科学感兴趣，也许你想学 R。但我特别推荐学习像 Racket 或 Elixir 这样的函数式语言。函数式编程需要一种不同的思考方式，它会改变你对程序的思考方式。

祝你好运！
