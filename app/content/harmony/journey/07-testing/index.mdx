## 阶段概述

应用测试是确保应用质量的重要环节。在这个阶段，你需要学习单元测试、UI 测试、应用专项测试等方法，确保应用在发布前达到质量标准。

## 学习目标

通过本阶段的学习，你将能够：

- 编写单元测试和 UI 测试
- 使用自动化测试框架
- 进行应用专项测试（漏洞、隐私、兼容性、稳定性、性能）
- 使用 DevEco Testing 进行测试
